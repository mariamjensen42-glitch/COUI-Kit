# Navigation

## Overview
导航包提供宿主受控的导航外观：`NavigationBar` 以玻璃胶囊菜单加左右配件按钮，`DockBar` 为胶囊停靠栏与可选中央圆钮，`SideNavigationBar` 在 docked 与抽屉间切换，另含 `NavigationRail`、`BottomFloatingNavigationBar` 与 `AccessoryNavigationBar`。选择、展开和可见状态全部由宿主传入，包内不持有导航提交。`Coui*Defaults` 提供不可变的 metrics、colors 与固定 token。

## Invariants
- `NavigationBar` 要求 `items` 非空且 `selectedIndex` 在范围内；`leftVisible` / `rightVisible` 需要对应图标与描述非空；无 `onClick` 的配件仍可拖动但不安装点击与 Button 语义。`[NavigationBar.kt:NavigationBar]`
- 菜单选择为“预览后提交”：拖动只改 `previewSelection`；`onSelection` 由 `couiNavigationReleaseTarget` 在 UP 或语义 Enter/Space 且索引变化时触发，`pointerInput` 的 finally 把预览复位到 `selectedIndex`。`[NavigationBar.kt:NavigationBar]` `[CouiFabExpansion.kt:couiNavigationReleaseTarget]`
- `CouiFabExpansion.updateTarget` 在菜单或 FAB 尺寸非正时忽略；布局对变化直接吸附到目标并重建弹簧，后续可见性变化只改目标、保留当前值与速度。缩放目标为 1f/0.5f，阶段结束分别置 `interactive`、`touchMotionEnabled` 或 `present`。`[CouiFabExpansion.kt:updateTarget]`
- 收起方向：左配件 `collapseToLeft = layoutDirection == Ltr`，右配件为 `layoutDirection == Rtl`；`hiddenTranslation = (collapseToLeft ? menu.left : menu.right - fab.width) - fab.left`。`[NavigationBar.kt:NavigationBar]` `[CouiFabExpansion.kt:couiFabHiddenTranslation]`
- `NavigationBar` 宽度上限为 `24.dp + 70.dp * items.size + 8.dp * (items.size - 1) + 136.dp`，实际菜单宽为 `(maxWidth - 136.dp).coerceAtLeast(0.dp)`；行与配件高 56.dp、配件宽 56.dp。`[NavigationBar.kt:NavigationBar]`
- `DockBar` 要求非空且在范围内的 `selectedIndex`；`capsuleWidth = itemWidth * items.size + horizontalPadding * 2`；仅 `centerIcon != null` 时渲染中央按钮；已选项不重复触发 `onSelection`；胶囊与中央按钮各用独立 `GraphicsLayer` 与渲染器，中央 `foregroundComposition = true`。`[DockBar.kt:DockBar]`
- `SideNavigationBar` 要求非空且在范围内；模式为 `docked ?: (maxWidth >= dockedMinWidth)`，docked 宽为 `min(dockedMaxWidth, maxWidth * dockedWidthFraction)`；抽屉只在进度 > 0.001f 时组合，遮罩只在 > 0f 时组合；不安装返回键或边缘滑动。`[SideNavigationBar.kt:SideNavigationBar]`
- `NavigationRail` 要求非空且在范围内；间距为 `max((availableHeight * menuHeightFactor - totalItemHeight) / (itemCount + 1), minItemSpacing)`，item 固定宽 `menuWidth + itemHorizontalMargin * 2`，无限高约束时容器高取块高；item 组合顺序为图标上留白、图标、标签上留白、两行文本、下留白。`[NavigationRail.kt:NavigationRail]` `[NavigationRail.kt:NavigationRailItem]`
- `BottomFloatingNavigationBar` 要求非空且在范围内；item 受 `heightIn` / `widthIn` 限制，标签 10.sp 单行省略；整行使用记忆化的 `horizontalScroll`；`BottomFloatingAccessory` 是被动固定框，不含点击处理。`[BottomFloatingNavigationBar.kt:BottomFloatingNavigationBar]` `[BottomFloatingNavigationBar.kt:BottomFloatingAccessory]`
- `AccessoryNavigationBar` 要求非空且 `collapsedVisibleCount >= 0`；隐藏项在 `visible || alpha > 0.001f` 期间保留组合；动画只读取 `alphaResponse`、`scaleResponse`、`scaleBounce`，`translationResponse` / `translationBounce` 未被引用；`stiffness(0f)` 返回 `Float.POSITIVE_INFINITY`。`[AccessoryNavigationBar.kt:AccessoryNavigationBar]` `[CouiAccessoryNavigationBarDefaults.kt:CouiAccessoryNavigationBarDefaults.stiffness]`
- 所有导航栏的选择状态归宿主：只以 `index == selectedIndex` 判定选中，点击仅调用 `onSelection(index)`；显式 `dark` 与其默认 `colors` 必须同源，否则调色板与状态蒙版明暗不一致。`[NavigationRail.kt:NavigationRailItem]` `[BottomFloatingNavigationBar.kt:BottomFloatingNavigationItem]` `[AccessoryNavigationBar.kt:AccessoryNavigationBar]`
- `NavigationBar` 与 `DockBar` 的 `backdrop` 默认 `checkNotNull(LocalCouiBackdrop.current)`，缺失时组合失败而非回退。`[NavigationBar.kt:NavigationBar]` `[DockBar.kt:DockBar]`

## Side Effects
- 消费 `LocalCouiBackdrop`、`LocalCouiContourGlowEnabled`、`LocalDensity`、`LocalLayoutDirection`；`SideNavigationBar` 用布局方向镜像抽屉滑入方向。`[NavigationBar.kt:NavigationBar]` `[DockBar.kt:DockBar]` `[SideNavigationBar.kt:SideNavigationBar]`
- `NavigationBar` 与 `DockBar` 通过 `ProvideCouiContent` 为每个 item 标题提供内容色。`[NavigationBar.kt:NavigationBar]` `[DockBar.kt:DockBar]`
- 平台 insets：`WindowInsets.tappableElement.getBottom(density)` 选择 0.dp 或 8.dp 底边距；`NavigationBar` 对 tappableElement 应用 `windowInsetsPadding`（Horizontal + Bottom）。`[NavigationBar.kt:NavigationBar]`
- 无障碍：item 注册 `Role.Tab`、`selected` 与 `onClick`，容器 `selectableGroup`，支持 `focusable` 与 Enter/Spacebar；配件与中央按钮用 `Role.Button`；禁用配件使用 `clearAndSetSemantics`。`[NavigationBar.kt:FloatingNode]` `[DockBar.kt:DockBar]` `[SideNavigationBar.kt:SideNavigationRow]`
- 指针输入：菜单行使用自定义 `pointerInput` 循环（Main 通道、消费全部变化、`isCouiTouchCancelled`），并叠加 `couiTouchMotion` / `couiPressMotion`；`selectable` / `clickable` 的 indication 为 null。`[NavigationBar.kt:NavigationBar]` `[NavigationRail.kt:NavigationRailItem]`
- 渲染后端：`CouiBackdrop`、`CouiFloatingRenderer`、`rememberGraphicsLayer` 录制、`LocalCouiContourGlowEnabled` 轮廓光与 `rememberCouiSpotlight` 聚光。`[NavigationBar.kt:NavigationBar]` `[DockBar.kt:DockBar]`
- 平台 API：`NavigationBar` / `DockBar` 标注 `@RequiresApi(33)` 并使用 `android.graphics.BlendMode`；配件展开使用 `androidx.dynamicanimation` 的 `SpringAnimation`；主题读取 `CouiTheme.isDark`、`materialTintFor`、`colorSchemeFor` 与 `shapes`。`[NavigationBar.kt:NavigationBar]` `[DockBar.kt:DockBar]` `[CouiFabExpansion.kt:CouiFabExpansion]`
