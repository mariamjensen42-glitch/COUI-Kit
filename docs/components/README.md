# 组件目录

需要在布局中直接使用控件时，从这里选择。可以只使用一个组件，也可以和其他设计体系混搭；不要求替换宿主 Scaffold、主题或导航。首次接入见[快速开始](../guide/getting-started.md)，页面装配见[宿主页面接入](../guide/secondary-pages.md)。

下文按抽象程度分层，从设计变量、原子件、布局容器到具体场景依次排列。分层只用于定位，不限制组合方式；Demo 目录仍按使用场景分组，两者的对应关系见文末[场景速查](#场景速查)。

## 基础规范

配色、排版、轮廓与动效由 `CouiTheme` 和各项 `Defaults` 持有，没有独立控件页：`CouiTheme.colorScheme`、`typography`、`shapes` 提供全局值，`CouiPageDefaults` 与各组件的 `*Defaults` 持有固定尺寸。接入与局部覆盖见[外观与预设](../guide/appearance.md)，缓动、弹簧与跟手参数见[动效](../effects/motion.md)。

| 场景 | 主要落层 |
